Las pruebas estan por orden de dificultad:

0. Hello world, todos los programas deberian correrlo. 
    | Nivel de dificutad: 1/5

1. Calculadora, disenado para probar elementos del lenguaje .y
    | Nivel de dificultad 3/5

2. Lista doblemente enlazada, disenado para probar objetos del .z
    | Nivel de dificultad 3/5

3. Laberinto, prueba elementos mixtos en los tres lenguajes
    | Incluye manejo de objetos y arreglos complejos
    | Nivel de dificutad 5/5

4. Ahorcado, prueba elementos mixtos en los tres lenguajes
    | Incluye manejo de objetos
    | Nivel de dificultad 5/5

Ruta de calificacion (propuesta):
    Hello world y algun archivo complejo (3 o 4) en caso de que el proyecto este completo. 
    En el caso en que el proyecto no este completo, se podria probar el Hello World junto con la calculadora y la lista doblemente enlazada individualmente, para evaluar separadamente los lenguajes.
